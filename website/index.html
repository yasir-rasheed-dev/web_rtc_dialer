One platform for calling, campaigns and oversight

Every capability below ships in the same app and is gated by a ~70-permission role system, so each agent only sees what their role allows.

WebRTC softphone

A real SIP phone in the browser — one registration per session.

  • Outbound & inbound, mute, hold / resume, DTMF keypad
  • Blind and warm / attended transfer (same tenant)
  • Add participant — multi-party conference bridge
  • Contact caller-ID resolution, per-agent outbound DID

Call recording

MixMonitor recording on outbound, inbound-to-agent and toll-free queue legs.

  • Permission-gated per agent
  • Inline playback on every call-log row
  • Dedicated Recordings page with themed audio player

Voicemail

Declined / unanswered calls fall through to voicemail (opt-in per role).

  • Capture via the dialplan, served through the API
  • Themed player, unread badge counts
  • Real duration computed from the WAV

Call logs & dispositions

Full history with date / agent / search filters and pagination.

  • Editable disposition from the logs
  • Shared per-tenant disposition list (name + colour)
  • End-Call popup: client details, follow-up date, remarks, attachments, tags
  • Call participants column across transfers

Leads & follow-ups

Persistent customer records that accumulate interaction history across calls.

  • Name / phone / address, latest-disposition mirror, tags, attachments
  • Follow-ups dashboard — all / today / missed, with a due badge

Contacts

Contacts with multiple phone numbers and addresses each.

  • Create / edit / delete, each permission-gated
  • Lookup by number → name, company, job title

Auto dialer

Outbound campaigns with ring strategy and per-campaign dispositions.

  • Contact upload (XLSX / CSV) & assignment to agents
  • Contact locking — two agents never get the same record
  • Agent auto-dial flow with skip & disposition capture
  • Campaign reports with export

Toll-free & IVR

Toll-free numbers and inbound queue campaigns.

  • Dynamic, data-driven IVR — greetings & digit options stored in the DB
  • No static dialplan edits per IVR
  • Toll-free live dashboard and reports

Live supervisor monitoring

Active-calls board across the workspace and supervised teams.

  • Listen (monitor), Whisper and Barge via ChanSpy
  • Each a separate permission, scoped to the supervisor's teams
  • Monitoring legs never appear in call logs

Teams

Teams with members and supervisors.

  • Team-scoped data access — calls, recordings, voicemails, leads, reports
  • Per-team monitoring privileges (monitor / listen / whisper / barge)

Users & agents

User CRUD with role assignment and automatic SIP provisioning.

  • Tenant-aware SIP usernames, local extension allocation, optional per-agent DID
  • Live agent status (Ready / On-Call / …)
  • TOTP two-factor authentication with QR enrolment

Roles & permissions

Dynamic roles per workspace with a ~70-permission catalog.

  • Call & Media, Dashboards, Supervisor, Auto Dialer, Toll-Free, Compliance, Billing, Security
  • Permission-driven menus & buttons, enforced on every backend route
  • Single active session per user

Phone numbers / DIDs

DID inventory, assignment to agents and routing profiles.

  • Purchase numbers via Commio (feature-flagged per tenant)
  • Pending-order tracking and carrier reconciliation

DNC & compliance

Do-Not-Call list management by import or manually.

  • Calls to DNC numbers blocked
  • Explicit override permission for authorised roles

Dashboards & reports

Agent and owner dashboards, plus a full reports hub.

  • Call reports with PDF / Excel export
  • Agent performance report — ordered by most dialed
  • Campaign & toll-free reports; per-tenant usage & minutes

Team chat

Real-time chat on Firebase — channels and direct messages.

  • Emoji picker, file attachments
  • Desktop push notifications (FCM), also inside the desktop app

Multi-tenancy & security

Workspace + email + password login; every record is tenant-scoped.

  • Tenant-aware Socket.IO rooms & Asterisk routing
  • JWT auth, bcrypt, TOTP 2FA, AES-256-GCM for stored secrets
  • Helmet headers, rate limiting, strict CORS allowlist
Calling

A softphone that handles the whole call

Answer, transfer, conference and wrap up without leaving the page — and pop the call out into an always-on-top window in the desktop app.

  • Mute, hold / resume, DTMF, blind & warm transfer
  • Add participant into a multi-party bridge
  • Detachable always-on-top call window (desktop)
  • End-Call popup with disposition, follow-up & save-to-contact

Supervision

Listen, whisper or barge — live

Supervisors see every active call across their teams and can step in three ways, each a separate permission. Monitoring legs are invisible in the call logs and drop the instant the call ends.

  • Listen — silent monitor
  • Whisper — coach the agent, caller can't hear
  • Barge — join the call, three-way
  • Scoped per team — a supervisor only monitors their own

Numbers you can export and act on

  • Agent performance — dialed, connected, talk time, voicemails
  • Campaign & toll-free reports
  • Usage — seat counts and inbound / outbound minutes
